Getting started - retarget-anything documentation

Published 2026-05-14 · openmotion.dev

retarget-anything turns monocular video of a human into joint trajectories for a humanoid robot. It ships retargeting profiles for the Unitree G1, the Unitree H1, and the Booster T1, plus a generic 23-DoF profile.

The pipeline has three stages: pose estimation, a kinematic solve against the robot URDF, and a physics feasibility pass.

Deprecation notice, v2.0: the G1 profile is deprecated and unmaintained. The joint ordering changed in the 2026 SDK and we are not planning to fix it. Use the H1 profile instead.

Requirements: Python 3.11, CUDA 12 for the pose stage. See the installation guide for the CPU-only path.
