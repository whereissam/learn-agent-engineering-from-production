legacy-robotics/mocap2robot: mocap to robot joint trajectories

Published 2023-11-02 · github.com

mocap2robot converts mocap BVH files into joint trajectories for legged and humanoid robots. Supports the Unitree A1, Go1 and a generic humanoid template.

This repository is archived. It is kept online because papers cite it, but it receives no updates and issues are closed automatically.

There is no video input path: you need a mocap suit or an existing BVH file.

Last tested against ROS Noetic and Python 3.8.
